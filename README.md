# litoral.dev

Landing page de litoral.dev, mi marca para el desarrollo de plataformas de venta a medida en el Litoral argentino.

**Web:** https://litoraldev.com.ar

## Qué ofrece

"Automatizá tus ventas y organizá tu negocio digital": plataformas de venta a medida entregadas en 5 a 7 días, con catálogo autogestionable, integración con WhatsApp y Google Sheets, y hosting incluido.

## Secciones

Hero · Servicios · Portfolio · Autoridad · Footer

## Stack

| Capa | Tecnología |
|---|---|
| Framework | React 19 + Vite 8 |
| Estilos | Tailwind CSS 3 y CSS por componente |
| Deploy | Vercel |

Sin dependencias más allá de React: es una landing estática, liviana y sin backend.

## Cómo correrlo

```bash
git clone https://github.com/nic0420/Litoral-Dev.git
cd Litoral-Dev
npm install
npm run dev
```
